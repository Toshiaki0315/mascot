# Desktop Mascot App

Tauri (Rust + TypeScript) を使用した macOS 向けデスクトップマスコットアプリです。

## 開発環境の構築
1. **前提条件**:
   * Node.js (v18以降を推奨)
   * Rust / Cargo
   * macOS 開発環境 (Xcode Command Line Tools)
2. **依存関係のインストール**:
   プロジェクトルートで以下のコマンドを実行します。
   ```bash
   npm install
   ```

## 開発の仕方
開発モードで起動するには、以下のコマンドを実行します。
```bash
npm run tauri dev
```
※ 初回起動時はRustのコンパイルが行われるため、数分程度時間がかかります。

## アプリの使い方
*   アプリを起動すると、デスクトップ上にマスコットが表示されます。
*   マスコットは常に最前面に表示されますが、キャラクター以外の透明な部分はクリックを透過するため、背後のアプリの操作を邪魔しません。
*   マスコットは画面内（メニューバーと Dock を除く範囲）をランダムに歩き回り、目的地に着くと数秒休みます。
*   キャラクターにマウスを重ねると操作可能になり、その間は立ち止まります。ドラッグで好きな場所へ移動できます。
*   アプリの終了や設定は、メニューバー（画面右上）に表示されるトレイアイコンから行ってください。

## ビルド
リリースビルドを作成するには以下のコマンドを実行します。
```bash
npm run tauri build
```
