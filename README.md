# Desktop Mascot App

Tauri v2 (Rust + TypeScript) を使用した macOS 向けデスクトップマスコットアプリです。
ドット絵のネコがデスクトップ上を歩き回ります。

## インストール
1. [Releases](https://github.com/Toshiaki0315/mascot/releases) から最新の `.dmg` をダウンロードして開きます。
2. `Desktop Mascot.app` を「アプリケーション」フォルダへドラッグします。

*   **Apple Silicon (M1 以降) 専用**です。Intel Mac では動きません。
*   コード署名・公証をしていないため、初回起動時に macOS にブロックされます。「システム設定 → プライバシーとセキュリティ」の「このまま開く」から起動してください。うまくいかない場合はターミナルで次を実行してください。
    ```bash
    xattr -dr com.apple.quarantine "/Applications/Desktop Mascot.app"
    ```

## 開発環境の構築
1. **前提条件**:
   * Node.js (v20.19 以降、または v22.12 以降。Vite 8 の要件)
   * Rust / Cargo
   * macOS 開発環境 (Xcode Command Line Tools)
2. **依存関係のインストール**:
   プロジェクトルートで以下のコマンドを実行します。
   ```bash
   npm install
   ```

## コマンド
よく使う操作は `make` で実行できます（`npm install` が済んでいなければ自動で実行されます）。

| コマンド | 内容 | 出力先 |
| --- | --- | --- |
| `make dev` | 開発モードで起動（ホットリロード） | — |
| `make app` | リリースビルドの `.app` を作成 | `src-tauri/target/release/bundle/macos/` |
| `make dmg` | 配布用の `.dmg` を作成（`.app` も残る） | `src-tauri/target/release/bundle/dmg/` |
| `make icon` | `scripts/gen-icon.mjs` からアプリアイコンを作り直す | `src-tauri/icons/` |
| `make clean` | ビルド成果物を削除 | — |

※ 初回はRustのコンパイルが行われるため、数分程度時間がかかります。
※ 作成した `.app` / `.dmg` はコード署名・公証をしていないため、他の Mac で開くと macOS にブロックされます。開き方は「[インストール](#インストール)」を参照してください。

## アプリの使い方
*   アプリを起動すると、デスクトップ上にドット絵のマスコットが表示されます。Dock には表示されません。
*   マスコットは常に最前面に表示されますが、キャラクター以外の透明な部分はクリックを透過するため、背後のアプリの操作を邪魔しません。キーボードフォーカスも奪いません。
*   マスコットは画面内（メニューバーと Dock を除く範囲）をランダムに歩き回り、目的地に着くと数秒休みます。画面が複数あるときは、ときどき別の画面へ遠出します。
*   キャラクターにマウスを重ねると操作可能になり、その間は立ち止まります。

| 操作 | 動作 |
| --- | --- |
| クリック | ぴょんぴょん跳ねて喜ぶ（^ ^ の顔とハート） |
| ダブルクリック | くるっと 1 回転する |
| ドラッグ | 好きな場所へ移動する |

ほかにも、ひとりでこんなことをします。

*   **カーソルを目で追う**: 近くにカーソルがあると、そちらへ目を向けます。歩いている間は進む方を見ます。
*   **眠る**: キーボード・マウスの入力が 60 秒ないと、目を閉じて Zzz… と眠ります。何か操作すると起きます。
*   **休憩中のしぐさ**: 立ち止まったとき、ときどきあくびや伸びをします。
*   **全画面アプリの上では隠れる**: 動画やプレゼンなど、ほかのアプリが画面全体を覆っている間は姿を消し、終わると戻ってきます。

### トレイメニュー
メニューバー（画面右上）のネコのアイコンから操作します。設定は保存され、次回起動時も引き継がれます。

| 項目 | 内容 |
| --- | --- |
| 表示 / 非表示 | マスコットを出したりしまったりする |
| 歩き回る | オフにするとその場にとどまる |
| 歩く速さ | ゆっくり / ふつう / はやい |
| 大きさ | 0.5 倍 / 1 倍 / 2 倍 |
| 全画面アプリの上では隠れる | オフにすると全画面アプリの上にも表示する |
| ログイン時に起動 | Mac にログインしたら自動で起動する |
| 終了 | アプリを終了する |

*   マスコットの位置と表示 / 非表示の状態も保存され、次回は同じ場所から始まります。外したモニターの上にいた場合は、メイン画面の右下に戻ってきます。
*   設定ファイルは `~/Library/Application Support/jp.classmethod.desktop-mascot/settings.json` です。

## カスタマイズ
*   **見た目**: [src/sprite.ts](src/sprite.ts) に 16×16 のドット絵を文字列で定義しています。文字を書き換えるとキャラクターや表情が変わります。色は [src/styles.css](src/styles.css) の `.px-*` で指定しています。
*   **アプリアイコン・トレイアイコン**: [scripts/gen-icon.mjs](scripts/gen-icon.mjs) のドット絵と色を書き換えて `make icon` を実行すると、全サイズのアイコンが作り直されます。
*   **歩く速さ**: [src-tauri/src/settings.rs](src-tauri/src/settings.rs) の `Speed::px_per_sec` で、メニューの各速さ（論理ピクセル/秒）を変えられます。
*   **休む時間・眠るまでの時間**: [src-tauri/src/wander.rs](src-tauri/src/wander.rs) 先頭の `IDLE_MIN_MS` / `IDLE_MAX_MS`（ミリ秒）、`SLEEP_AFTER_SECS`（秒）で調整できます。

## 仕組み
*   **クリックスルー**: ウィンドウは通常 `set_ignore_cursor_events(true)` で全体がクリックを透過します。透過中は WebView にマウスイベントが届かないため、Rust 側がカーソル位置をポーリングしてフロントエンドへ送り、TypeScript 側でキャラクターのドットに重なっているかを判定して、Rust の `set_click_through` コマンドで透過の ON/OFF を切り替えます。
*   **ランダム移動**: Rust 側のスレッドがウィンドウの位置を少しずつ動かし、進行方向をフロントエンドへ通知して、歩くアニメーションと視線を切り替えます。座標はすべて macOS のポイント単位で扱うので、倍率の違うモニターをまたいでもずれません。
*   **眠る・全画面の検出**: macOS の CoreGraphics から、最後の入力からの経過秒数と、画面に出ているウィンドウの一覧を読みます。どちらも画面収録などの権限は不要です。

## プロジェクト構成
```
├── Makefile                # make dev / app / dmg / icon
├── index.html              # キャラクターを描く SVG の入れ物
├── scripts/gen-icon.mjs    # アプリアイコン（ドット絵）の生成スクリプト
├── src/
│   ├── main.ts             # ホバー判定、クリック・ドラッグ、視線、しぐさ
│   ├── sprite.ts           # ドット絵の定義と SVG への描画
│   └── styles.css          # 色とアニメーション
└── src-tauri/
    ├── tauri.conf.json     # ウィンドウ設定（透過・最前面・フォーカスなし、148×158）
    ├── capabilities/       # フロントエンドに許可する API
    └── src/
        ├── lib.rs          # 起動処理、クリックスルー、カーソル監視、大きさの変更
        ├── tray.rs         # トレイアイコンと設定メニュー
        ├── wander.rs       # 歩き回る・眠る・全画面で隠れる、を決めるスレッド
        ├── geometry.rs     # 画面・ウィンドウの座標計算（マルチモニター対応）
        ├── system.rs       # macOS の入力経過時間・ウィンドウ一覧の取得
        └── settings.rs     # 設定と位置の保存・読み込み
```
