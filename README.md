# Desktop Mascot App

Tauri v2 (Rust + TypeScript) を使用した macOS 向けデスクトップマスコットアプリです。
ドット絵のネコ（またはいぬ）がデスクトップ上を歩き回り、開いている窓の上に乗ったり、ふきだしで話しかけてきたりします。リマインダー、タイマー、ポモドーロ、メモ、天気の知らせにも使えます。

## インストール
1. [Releases](https://github.com/Toshiaki0315/mascot/releases) から最新の `.dmg` をダウンロードして開きます。
2. `Desktop Mascot.app` を「アプリケーション」フォルダへドラッグします。

*   **Apple Silicon (M1 以降) 専用**です。Intel Mac では動きません。
*   アドホック署名のみで、Apple Developer ID による署名・公証はしていないため、他の Mac では初回起動時に macOS にブロックされます。「システム設定 → プライバシーとセキュリティ」の「このまま開く」から起動してください。うまくいかない場合はターミナルで次を実行してください。
    ```bash
    xattr -dr com.apple.quarantine "/Applications/Desktop Mascot.app"
    ```

## 開発環境の構築
1. **前提条件**:
   * Node.js (v20.19 以降、または v22.12 以降。Vite 8 の要件)
   * Rust / Cargo
   * macOS 開発環境 (Xcode Command Line Tools)
2. **依存関係のインストール**:
   プロジェクトルートで以下のコマンドを実行します。
   ```bash
   npm install
   ```

## コマンド
よく使う操作は `make` で実行できます（`npm install` が済んでいなければ自動で実行されます）。

| コマンド | 内容 | 出力先 |
| --- | --- | --- |
| `make dev` | 開発モードで起動（ホットリロード） | — |
| `make app` | リリースビルドの `.app` を作成 | `src-tauri/target/release/bundle/macos/` |
| `make dmg` | 配布用の `.dmg` を作成（`.app` も残る） | `src-tauri/target/release/bundle/dmg/` |
| `make icon` | `scripts/gen-icon.mjs` からアプリアイコンを作り直す | `src-tauri/icons/` |
| `make test` | テストを実行（フロントエンド + Rust） | — |
| `make check` | CI と同じ確認（型チェック・テスト・`cargo fmt`・`clippy`） | — |
| `make e2e` | 画面まわりの回帰テスト（[後述](#画面まわりの回帰テスト)） | — |
| `make bump` | バージョンを上げる（`LEVEL=minor` / `major`、または `VERSION=1.2.3`） | 関係する 5 つのファイル |
| `make notes` | リリースノートの下書きを出す（`TAG=v1.2.3`） | 画面に出す |
| `make clean` | ビルド成果物を削除 | — |

※ 初回はRustのコンパイルが行われるため、数分程度時間がかかります。
※ 作成した `.app` / `.dmg` にはアドホック署名（`tauri.conf.json` の `signingIdentity: "-"`）が付きますが、Developer ID 署名・公証はしていないため、他の Mac で開くと macOS にブロックされます。開き方は「[インストール](#インストール)」を参照してください。

## アプリの使い方
*   アプリを起動すると、デスクトップ上にドット絵のマスコットが表示されます。Dock には表示されません。
*   起動できるのは 1 つだけです。すでに動いているときにもう一度起動すると、動いている方のマスコットが表示されます（非表示にしていた場合も出てきます）。
*   マスコットは常に最前面に表示されますが、キャラクター以外の透明な部分はクリックを透過するため、背後のアプリの操作を邪魔しません。キーボードフォーカスも奪いません。
*   マスコットは画面内（メニューバーと Dock を除く範囲）をランダムに歩き回り、目的地に着くと数秒休みます。画面が複数あるときは、ときどき別の画面へ遠出します。
*   キャラクターにマウスを重ねると操作可能になり、その間は立ち止まります。

| 操作 | 動作 |
| --- | --- |
| クリック | ぴょんぴょん跳ねて喜ぶ（^ ^ の顔とハート） |
| ダブルクリック | くるっと 1 回転する |
| ドラッグ | 好きな場所へ移動する |
| ドラッグして勢いよく離す | 投げる。画面の端で跳ね返り、床に着地する |

ほかにも、ひとりでこんなことをします。

*   **窓の上に乗る**: ときどき、開いている窓のふち（上端）にぴょんと飛び乗り、ふちに沿って歩きます。窓を動かすと一緒に動き、窓を閉じたり最小化したりすると落ちてきます。手前の窓に隠れているふちには乗りません。
*   **カーソルを目で追う**: 近くにカーソルがあると、そちらへ目を向けます。歩いている間は進む方を見ます。
*   **眠る**: キーボード・マウスの入力が 60 秒ないと、目を閉じて Zzz… と眠ります。何か操作すると起きます。
*   **休憩中のしぐさ**: 立ち止まったとき、ときどきあくびや伸びをします。
*   **ふきだしでおしゃべり**: 毎時 0 分の時報、休憩せずに 50 分作業を続けたときの「そろそろ休憩しよう？」、クリックされた・投げられた・目を覚ましたときのひとことなどを、頭の上のふきだしで話します。
*   **画面を見ていないときは止まる**: 画面がロックされている間、ディスプレイが消えている間、別のユーザーに切り替わっている間は、動きもカーソルの監視もやめて、電池を使いません（リマインダーとタイマーの時刻は、そのまま見張ります）。戻ると、続きから動き出します。
*   **全画面アプリの上では隠れる**: 動画やプレゼンなど、ほかのアプリが画面全体を覆っていてメニューバーも消えている間は姿を消し、終わると戻ってきます。

### トレイメニュー
メニューバー（画面右上）のネコのアイコンから操作します。設定は保存され、次回起動時も引き継がれます。

| 項目 | 内容 |
| --- | --- |
| Desktop Mascot について | バージョン・ビルドしたコミット・著作権を表示する |
| 表示 / 非表示 | マスコットを出したりしまったりする |
| リマインダー | 「リマインダーの画面を開く…」と、直近の予定 5 件（押すと画面が開く） |
| タイマー | 「タイマーの画面を開く…」、3 / 5 / 10 分タイマーの開始、動いているタイマー |
| ポモドーロ | 「ポモドーロの画面を開く…」、いまの状態（作業中 / 休憩中と終わる時刻）、始める・止める |
| メモ | 「メモの画面を開く…」、クリップボードをメモに保存、直近のメモ 5 件（押すとコピー） |
| 今日の天気 | 「天気の画面を開く…」（場所と時刻の設定）、今日の天気を見る |
| キャラクター | 茶トラ / 黒ネコ / 白ネコ / 三毛ネコ / いぬ / くらにゃんぽい |
| 設定… | 設定のウィンドウを「一般」の見出しで開く（下の「設定ウィンドウ」を参照） |
| 終了 | アプリを終了する |

*   マスコットの位置と表示 / 非表示の状態も保存され、次回は同じ場所から始まります。外したモニターの上にいた場合は、メイン画面の右下に戻ってきます。
*   設定ファイルは `~/Library/Application Support/jp.classmethod.desktop-mascot/settings.json` です。
*   「メニューバーを自動的に表示 / 非表示」を使っていると、画面いっぱいに広げた窓を全画面と見分けられず、マスコットが隠れることがあります。その場合は「全画面アプリの上では隠れる」をオフにしてください。

### 右クリックメニュー
マスコットを右クリックすると、トレイと同じメニューがその場に出ます。

### 設定ウィンドウ（一般・リマインダー・タイマー・ポモドーロ・メモ・天気）
メニューの「設定…」や「リマインダーの画面を開く…」などで開く 1 つのウィンドウに、6 つの見出しがあります。

*   **一般**: 歩き回る、歩く速さ（ゆっくり / ふつう / はやい）、大きさ（0.5 / 1 / 2 倍）、おしゃべり、全画面アプリの上では隠れる、ログイン時に起動。変えるとすぐ保存して反映します。キャラクターだけは、メニューから選びます。

*   **リマインダー**: 内容（100 文字まで）、日付、時刻、くり返し（しない / 毎日 / 平日 / 毎週 / 隔週 / 毎月 / 曜日を選ぶ）、事前に知らせる時間（5 分前〜1 時間前）を登録します。編集と削除ができ、一覧は日時順・登録順で並べられます。
*   **タイマー**: 名前と分数を指定するカウントダウン。
*   **ポモドーロ**: 作業と休憩をくり返します（初期値は作業 25 分・休憩 5 分・4 回ごとに長い休憩 15 分）。区間の終わりに、キーボード・マウスの入力が 20 分以上なければ、離席中とみなして自動で止め、ふきだしで知らせます。
*   **メモ**: 一言のメモ（300 文字まで）を預けておき、あとでコピーして貼り付けます。クリップボードの内容をそのまま預けることもできます。
*   **天気**: 場所を決めて有効にすると、毎朝（指定した時刻を過ぎて最初に）今日の天気と気温、降水確率をふきだしで知らせます。取得には [Open-Meteo](https://open-meteo.com/)（キー不要）を使うので、ネットへの接続が要ります。

タイマーやポモドーロが動いている間は、メニューバーのネコの隣に残り時間が出ます（「🍅 12:30」「⏱ 2:41」など。両方動いていれば並べて出し、タイマーはいちばん早く終わるものだけを出します）。幅をとるので、タイマーとポモドーロそれぞれの画面の「設定」でオフにできます。タイマーは終わる 10 秒前から、ふきだしで「10、9、8…1」と秒読みをします。秒読みを出すかどうかは、タイマーの画面の「設定」で「ランダム（初期値。タイマーごとに半々で決まる）」「いつも出す」「出さない」から選べます。

音を鳴らすかどうかも、リマインダー・タイマー・ポモドーロそれぞれの画面の「設定」で切り替えます（初期値はすべて鳴らす）。

時刻になると、マスコットが跳ねて、頭の上の大きなふきだしで知らせます。ふきだしはマスコットとは別の透明なウィンドウで、文章（100 文字まで）に合わせて大きさが変わり、マスコットが動くと追いかけます。クリックして閉じます（リマインダーには「5 分後」にもう一度知らせるボタンもあります）。マスコットを非表示にしているときや、全画面アプリで隠れているときは、macOS の通知センターに出します。

## カスタマイズ
*   **見た目・キャラクター**: [src/sprite.ts](src/sprite.ts) に 16×16 のドット絵を文字列で定義しています。文字を書き換えるとキャラクターや表情が変わります。キャラクターごとの色は [src/styles.css](src/styles.css) の `#mascot.char-*` の CSS 変数で指定しています。
*   **セリフ**: [src/speech.ts](src/speech.ts) の `LINES`（場面ごとのセリフ）と `CHANCE`（話す確率）で変えられます。
*   **アプリアイコン・トレイアイコン**: [scripts/gen-icon.mjs](scripts/gen-icon.mjs) のドット絵と色を書き換えて `make icon` を実行すると、全サイズのアイコンが作り直されます。
*   **歩く速さ**: [src-tauri/src/settings.rs](src-tauri/src/settings.rs) の `Speed::px_per_sec` で、メニューの各速さ（論理ピクセル/秒）を変えられます。
*   **休む時間・眠るまでの時間・窓に乗る頻度など**: [src-tauri/src/wander.rs](src-tauri/src/wander.rs) 先頭の定数（`IDLE_MIN_MS` / `IDLE_MAX_MS`、`SLEEP_AFTER_SECS`、`PERCH_CHANCE`、`BREAK_REMIND_AFTER` など）で調整できます。投げたときの重力や跳ね返りは [src-tauri/src/physics.rs](src-tauri/src/physics.rs) にあります。

## 仕組み
*   **クリックスルー**: ウィンドウは通常 `set_ignore_cursor_events(true)` で全体がクリックを透過します。透過中は WebView にマウスイベントが届かないため、Rust 側がカーソル位置をポーリングしてフロントエンドへ送り、TypeScript 側でキャラクターのドットに重なっているかを判定して、Rust の `set_click_through` コマンドで透過の ON/OFF を切り替えます。
*   **ランダム移動**: Rust 側のスレッドがウィンドウの位置を少しずつ動かし、進行方向をフロントエンドへ通知して、歩くアニメーションと視線を切り替えます。座標はすべて macOS のポイント単位で扱うので、倍率の違うモニターをまたいでもずれません。
*   **窓に乗る・投げる**: 画面に出ているウィンドウの一覧から、ふちが見えている窓を選んで放物線で飛び乗ります。ドラッグ中はウィンドウの位置を記録しておき、マウスのボタンが離された瞬間の速さで投げます。
*   **眠る・全画面の検出**: macOS の CoreGraphics から、最後の入力からの経過秒数、マウスのボタンの状態、画面に出ているウィンドウの一覧を読みます。どれも画面収録やアクセシビリティなどの権限は不要です。
*   **省電力**: 飛んでいる・ドラッグ中は約 60fps、歩いている間は約 30fps で動かし、じっとしている間は 0.1 秒間隔に落とします。カーソルが遠い間は監視の間隔を延ばし、フロントエンドへも通知しません。ふきだしを出していない間は、ふきだしの追従も休みます。CPU の使用量は `scripts/measure-cpu.sh <アプリの実行ファイル>` で測れます。

## リリースの手順
1. バージョンを上げて、コミット・push します。
   ```bash
   make bump LEVEL=minor
   ```
   `make bump` だけなら 0.0.1 上がります（`LEVEL=major`、`VERSION=1.2.3` も使えます）。
2. 必要なら、リリースノートの下書きを確かめます（`make notes`）。前のタグからのコミットを、新機能・修正・変更に分けて出します。
3. `v` + バージョンのタグを push します。
   ```bash
   git tag v0.8.0
   ```
   ```bash
   git push origin v0.8.0
   ```
4. GitHub Actions（[.github/workflows/release.yml](.github/workflows/release.yml)）が dmg をビルドして、リリースに添付します。リリースがまだなければ、下書きのリリースノートで作ります（すでに作ってあれば、dmg だけを添付します）。タグと `tauri.conf.json` のバージョンが違うと失敗します。

push とプルリクエストのたびに、[.github/workflows/ci.yml](.github/workflows/ci.yml) で `make check` と同じ確認が走ります。

### 画面まわりの回帰テスト
`make e2e` で、全画面アプリの Space やプレゼンテーションの状態を実際に作り、マスコットとふきだしの出方を確かめます。

*   作業用のコピーに識別子を分けたテスト用のアプリを作るので、普段使っているアプリや設定には触れません
*   実行中は約 1 分、画面が切り替わります。本体の画面（内蔵ディスプレイ）を使い、実行中はマウスやキーボードに触らないでください
*   画面を操作するので CI では動きません。手元の Mac で実行します

## 今後の課題
*   **自動アップデート**: 新しい版を知らせ、入れ替えまで行う仕組み（Tauri の updater プラグイン）は、次の理由で見送っています。
    *   更新ファイルに署名する秘密鍵を、自動リリースのために GitHub のシークレットに預けることの安全性を見きわめたい
    *   近ごろのセキュリティ事情から、アプリが自分で更新されることを好まない人も多い
    *   入れるなら、設定で有効・無効を選べる形（既定は無効）にするのがよさそう
*   **省電力モード**: バッテリー駆動のときに動きをひかえめにする設定は、今回は見送りました。画面がロックされている間やディスプレイが消えている間は、すでに止まります。電力を使っている処理の洗い出しと、候補ごとの費用対効果、省電力モードの案は [docs/power-saving.md](docs/power-saving.md) に残しています。
